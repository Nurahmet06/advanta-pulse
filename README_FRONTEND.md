# ADVANTA Pulse — Frontend MVP (демонстрационный режим)

Запуск: откройте `frontend/index.html` через VS Code Live Server либо `python -m http.server 5500` из корня репозитория и откройте `/frontend/index.html`. Для GitHub Pages используйте относительные ссылки.

## Что добавлено
Директор: Обзор, Классы, Учителя, Тесты, Результаты, Аналитика. Администратор: Обзор и реестр сотрудников с созданием/одобрением заявок. Сотрудник: самостоятельная регистрация (заявка). Единый `frontend/js/language.js` для RU/KZ/EN. Вход теперь маршрутизирует роли на разные кабинеты. Существующие ученические и преподавательские страницы сохранены.

## ВАЖНЫЕ ОГРАНИЧЕНИЯ
Это только browser-only frontend. Нет реальной серверной авторизации, серверного контроля прав, безопасного реестра аккаунтов, синхронизации между компьютерами, серверного сброса пароля, СУБД и защищённого хранения персональных данных. Не используйте для реальных персональных данных учащихся/сотрудников. Не создавайте реальные административные пароли здесь.

Аккаунт администратора намеренно НЕ создаётся публичной кнопкой и НЕ имеет встроенных паролей. Для UI-демонстрации можно открыть `/frontend/admin-home.html` непосредственно: это не защита доступа. Начальная настройка реального администратора должна быть реализована backend.

`advantaStaffUsers` используется для локальных аккаунтов; `advantaUsers` — для учеников. Старые четыре теста без `teacherId` не прикреплены к учителям автоматически. Пока нет связи между локальным `teacher_math_1` и профилем сотрудника, этот ID отображается как технический.

### Проверки перед интеграцией backend
- Проверить навигацию всех 4 ролей, RU/KZ/EN по всем страницам и отсутствие ошибок в DevTools.
- Пройти путь регистрации ученика/сотрудника, одобрение, вход, назначение теста, выполнение, результат, аналитику.
- Заменить SHA-256 в браузере серверным безопасным хранением паролей и сессий; заменить localStorage на API.
- Добавить серверные правила доступа, миграцию данных, аудит и согласия на обработку персональных данных.

### GitHub
Создайте резервную копию текущего репозитория. Скопируйте содержимое ZIP в рабочую папку, проверьте `git status`, затем `git add . && git commit -m "Complete frontend MVP" && git push origin main`. Данные браузера в GitHub не загружаются. Не добавляйте `.env`, пароли или реальные личные данные.
